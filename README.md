# Ravens QB Completion Percentage Analysis

## Overview
Analysis of NFL quarterback completion percentages using NFLFastR play-by-play data.

## Tools Used
- Python
- NFLFastR
- Matplotlib
- Pandas

 ## Key Findings
- Built a custom Quarterback Completion Efficiency Rating (CER) 
  that expands on nflfastR's CPOE metric by incorporating air yards, 
  throw aggressiveness, QB pressure, and time to throw
- From 2022–2024, Geno Smith and Jalen Hurts led the league in CER, 
  with Lamar Jackson ranking in the top 10 — demonstrating elite 
  accuracy within a dynamic offensive system
- Higher air yards negatively correlate with completion percentage, 
  while quarterbacks with low sack percentages showed stronger 
  decision-making under pressure
- CPOE alone does not fully capture offensive efficiency — 
  incorporating trench and pressure metrics provides a more complete 
  evaluation of true QB performance
